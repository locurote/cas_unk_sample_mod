# cas_unk_sample_mod
Sample mod for Casualties Unknown using BepInEx

refer to the official [bepinex plugin guide](https://docs.bepinex.dev/master/articles/dev_guide/plugin_tutorial/index.html)  


adding bepinex nuget feed to sources  
`dotnet nuget add source https://nuget.bepinex.dev/v3/index.json --name bepinex.dev`

creating a template for bep 5 plugin for cas_unk 1.0.2  
`dotnet new bepinex5plugin -n SamplePlugin -T net472 -U 2022.3.62`
